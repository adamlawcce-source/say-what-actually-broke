A tiny Node 22 program for the make.fun bounty
[Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5).

`main.ts` writes one line of software error copy to `/output/entry.txt`: the
brutal truth about a server running out of memory mid-request, with what to
do next and a joke a reader repeats out loud. No network, no randomness, no
input — the same line on every run.

Run it with Node 22:

```sh
node main.ts
```
